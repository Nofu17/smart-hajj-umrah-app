# 🕋 Smart Hajj & Umrah Guide

An offline-first mobile application designed to assist Hajj and Umrah pilgrims with real-time group tracking, step-by-step rituals guidance, prayer times, and emergency SOS alerts — built to work reliably even without a stable internet connection.

## 📱 About the Project

Performing Hajj and Umrah involves navigating crowded holy sites, staying connected with travel groups, and following precise ritual steps — often under challenging network conditions. This app was built as a graduation project to address these real pilgrim needs through a smart, accessible mobile experience.

The project achieved an **A+ grade** and contributed to a research paper accepted by **IJARIIT**.

## ✨ Key Features

- 🗺️ **Haram Map** — Interactive map of the Holy Mosque with facilities (restrooms, Zamzam water stations, gates)
- 👥 **Group Tracking** — Create or join a group via QR code and track members' real-time location
- 📿 **Step-by-Step Rituals Guide** — Interactive walkthrough for Umrah, Hajj Tamattu', Qiran, and Ifrad
- 🔄 **Lap Counter** — Digital counter for Tawaf and Sa'i with session history
- 🕌 **Prayer Times** — Location-based prayer schedule with notifications
- 🧭 **Qibla Compass** — Real-time direction and distance to the Kaaba
- 🚨 **SOS Emergency Alerts** — One-tap location sharing with group members and support team
- 📖 **Du'a Collection** — Authenticated supplications for each stage of the journey
- 🏥 **Harem Services Directory** — Nearby hospitals, Zamzam stations, and lost & found
- 🌐 **Multi-language Support** — Arabic, English, Urdu, and Indonesian
- 📡 **Offline-First Design** — Core features work without an internet connection

## 🛠️ Built With

- **Flutter** — Cross-platform mobile framework
- **Dart** — Programming language
- **Firebase** — Real-time group tracking and backend services
- **SQLite** — Local offline data storage
